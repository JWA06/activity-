This file contains next steps the admin should follow after cloning:

1. Create Supabase tables: sections, venues, events, posts, media, users.
   Example minimal SQL schema is provided in the README or create via Supabase UI.
2. Configure env vars in Vercel or locally (.env.local) using .env.example as a guide.
3. Run `npm run seed` to create sample data (requires SUPABASE_SERVICE_ROLE_KEY).
